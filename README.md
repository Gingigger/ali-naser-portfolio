# Ali Naser — Engineering Portfolio

Custom static portfolio built with HTML, CSS, and JavaScript.

## What's included
- Responsive premium dark/light interface
- Project case studies and proof galleries
- IEEE CASS 2026 competition evidence and report
- Smart Home hardware, dashboard, Telegram, gate, and sensor proof pulled from the submitted project package
- IEEEXtreme 20.0 Student Branch Ambassador selection
- Huawei Lebanon Elite Scholars Training Program 2026 selection
- Interactive lightbox, hover/tilt effects, reveal animations, and cover-letter customizer
- Downloadable CV and project reports

## Files
- `index.html` — portfolio structure/content
- `styles.css` — design, responsive layouts, and animations
- `script.js` — interactions and cover-letter tools
- `assets/` — CV, reports, evidence photos, and selection proof

## Open locally
Keep the entire folder together and open `index.html` in a browser.

For the most reliable local preview, run from this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish free
Upload the complete folder to GitHub Pages, Cloudflare Pages, Netlify, or Vercel.
